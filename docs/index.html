Offline-First

Builds precise symbol and dependency graphs directly with zero external network dependencies.

Incremental

Persistent SQLite graph updated in place via VCS synchronization without full rebuilds.

Standalone

Every client is a thin adapter over one shared public API and local daemon process.

Agent-Ready

Packed, token-budgeted prompt context and blast-radius analysis for autonomous workflows.
